# v0.1 Scope

This note defines the v0.1 release scope without expanding the compatibility
promise beyond the low-level wrapper contract.

## Stable v0.1 Surface

The stable v0.1 surface is exactly:

- `Pipeline`
- `Element`
- `Bus`
- `AppSink`
- `AppSource`
- `Buffer`
- `AudioBufferSink`
- `AudioBuffer`
- `VideoFrame`

These APIs are the supported low-level wrapper surface for direct GStreamer
work in v0.1.

## Source and Sink Builders

Source and sink builders, including `AudioSource`, `AudioFileSource`,
`VideoSource`, and `AudioSink`, are non-core convenience layers. Use them when
their platform and plugin choices match the application. Use direct `Pipeline`
construction for precise GStreamer control.

## Typed Pipeline DSL

The typed pipeline DSL is experimental and non-core. `VideoPipelineBuilder`,
`withPipeline`, and the typed frame wrappers provide convenience syntax, not the
stable v0.1 foundation.

## Finite File/Decode Reliable Delivery

Finite file/decode reliable delivery through `AudioFileSource.reliablePackets()`
has a scoped non-core contract. It is consumer-driven, each `ReliablePackets`
value supports one active consumer, iteration can throw pipeline failures, and
clean EOS is reached through iteration.

## Reliable Live Delivery

Reliable live delivery is experimental and non-core. It applies only to encoded
audio sources configured with explicit reliable delivery. It is not lossless
under sustained slowness; the live source, device driver, operating system, or
GStreamer pipeline can still impose backpressure or lose data.

## Known Limitations

- One bus drainer only.
- No bus fan-out.
- Reliable live source is not lossless under sustained slowness.
- Typed DSL is experimental.
- macOS/Linux verified only.
